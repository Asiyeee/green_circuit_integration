# ④ 구매자 목록 · 추천

루트에서 `npm start`, `/buyer`로 접속합니다. `buyer.html`은 공통 `ui.css`를 사용하고 `lib/buyer.js`가 통합 저장소의 판매 중 보증서를 읽습니다. 과거 독립 Express 서버/샘플 중앙값 방식은 사용하지 않습니다.

- 전체 목록은 파손·시세 없음·미확인 기능을 공개한 매물도 표시합니다. 상세 `/c/{id}`에서 보증서·사진·업체 원문과 판매 희망가를 확인하고 구매 문의/거래 요청을 저장합니다.
- 추천은 기종 부분 검색(한글·영문 표기/공백 정규화)과 중요 성능 3개를 사용합니다. 선택 성능 중 미확인·60점 미만 항목은 추천에서 제외합니다. 전체 목록에는 유지됩니다. 카메라 사진 화질은 성능 비교용으로만 쓰고 외관/시세 등급으로 바꾸지 않습니다.
- 성능 우선순위는 50/30/20%. **모든 매물에서 가격 점수를 제외**합니다. 업체 매입가나 희망가 중앙값은 개인 거래 적정가의 검증된 기준이 아니기 때문입니다. `breakdown.price`는 호환을 위해 `null`로 유지합니다. 남은 성능/환경온도 가중치 0.4/0.25를 정규화해 약 61.5/38.5%로 계산합니다. 환경온도 36.5~40°C 점수 환산은 기존 데모용 기준이며 신원/거래 신뢰성을 검증하지 않습니다.
- 판매·기부·배출 완료와 유효기간 만료 매물은 판매 목록/추천에서 제외합니다. 상세/보증서 기록은 유지합니다. 다른 화면에서 완료됐으면 새로고침/재검색 시 반영됩니다.

API: `GET /api/public/certificates`, `GET /api/public/models`, `POST /api/public/recommend {device_model, priorities}`. 요청·소유권 API는 [통합 인계](../common/docs/PRICE_PLATFORM_HANDOFF.md) 참고.

`npm test`로 기존 추천 자체 점검과 통합 테스트를 실행합니다. 결제·에스크로·배송·실시간 채팅·실제 계정 인증은 구현 범위에 포함하지 않습니다.
