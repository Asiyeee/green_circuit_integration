# 스마트폰 처리 매뉴얼

확인일: 2026년 11월 2일  
적용 범위: 대한민국에서 아이폰 또는 삼성 갤럭시 스마트폰을 판매하거나 폐기하려는 사용자

문서 구성: 판매 준비·폐기 경로와 화면용 문구, 문서 끝의 개발 연결 규격. 초기화 경로는 공식 안내에 근거하며 모든 모델·운영체제 조합에서 직접 실행한 것은 아닙니다.

기기 진단 결과는 처리 방법을 선택할 때 참고합니다. 테스트한 항목의 결과만 보여주며, 확인하지 않은 기능까지 정상이라고 판단하지 않습니다. 고장 여부만으로 판매나 재활용을 강제하지 않고 사용자가 경로를 선택합니다.

## 처리 방법 선택

| 원하는 방법 | 안내 |
| --- | --- |
| 판매 | 기기 정보와 확인된 상태를 정리하고, 개인정보를 삭제한 뒤 거래를 준비합니다. |
| 폐기 | 기부를 통한 자원순환 또는 지역 수거함 등 배출 방법을 선택합니다. |

## 모든 경로에 공통으로 필요한 준비

1. 사진, 연락처, 인증 수단과 필요한 파일을 백업하고 새 기기에서 확인합니다.
2. 기기에 연결된 계정과 서비스의 연결 해제 방법을 제조사 안내에서 확인합니다. 유심과 별도 저장 매체도 확인합니다.
3. 필요한 자료가 보관된 것을 확인한 뒤 기기를 초기화합니다. 초기화하면 기기 안의 데이터가 삭제됩니다.
4. 고장 등으로 초기화하기 어렵다면 기기를 임의로 분해하지 말고 수거기관 또는 제조사에 문의합니다.

### 기종 선택에 따른 데이터 삭제 안내

아래는 기기 테스트 화면의 제조사·모델 선택값을 기준으로 보여줄 안내 초안입니다. 선택값은 사용자가 입력한 정보이므로 실제 기기와 일치하는지 확인해야 합니다. 메뉴는 운영체제 버전·지역에 따라 달라질 수 있으며, 모델명만으로 설치 버전을 알 수 없습니다. 표에 없는 조합은 확인되지 않은 경로로 표시합니다.

초기화 전 모든 기기에서 백업을 확인하고 유심·SD카드와 eSIM 이전 여부를 확인합니다. 다음 사용자에게 판매할 때는 기기에 연결된 계정을 제조사의 안내에 따라 해제합니다. 기기에서 계정을 제거하는 것은 계정 자체를 삭제하는 것과 다릅니다. 회사나 학교의 관리 기기는 관리자에게 먼저 문의합니다.

| 선택한 기종 | 보여줄 안내 | 확인 범위 |
| --- | --- | --- |
| 모든 아이폰 모델 | 아래 아이폰 안내 | 모델과 설치된 iOS 버전을 확인하고 해당 경로 선택 |
| Galaxy S·Note·Z·A 계열 | 아래 갤럭시 안내 | 모델·Android/One UI 버전별 차이 확인 필요 |

### 아이폰: 데이터 삭제 방법

먼저 **설정 → 일반 → 정보**에서 iOS 버전을 확인합니다. 선택한 모델만으로 버전을 확정하지 않습니다. [Apple의 버전 확인 안내](https://support.apple.com/ko-kr/guide/iphone/-iphe3fa5df43/ios)

1. 필요한 자료를 백업하고 새 기기에 옮겼는지 확인합니다. Apple Watch가 연결되어 있다면 페어링을 해제합니다.
2. Apple 계정에서 로그아웃합니다. **iOS 10.3 이상**은 **설정 → 사용자 이름 → 로그아웃**을 선택하고 화면 안내를 따릅니다. **iOS 10.2 이하**는 **설정 → iCloud → 로그아웃**을 누르고 안내에 따라 진행한 뒤, **설정 → iTunes 및 App Store → Apple ID → 로그아웃**도 확인합니다. 버전에 따라 화면이 다르며 계정 암호가 필요할 수 있습니다. [Apple의 버전별 로그아웃 안내](https://support.apple.com/ko-kr/109511)
3. iOS 15 이상은 **설정 → 일반 → 전송 또는 iPhone 재설정 → 모든 콘텐츠 및 설정 지우기**, iOS 14 이하는 **설정 → 일반 → 재설정 → 모든 콘텐츠 및 설정 지우기**를 선택합니다. 화면 지시에 따라 암호를 입력하고 삭제를 완료합니다. [Apple의 버전별 경로](https://support.apple.com/en-afri/120001)
4. 유심이 있다면 분리합니다. eSIM을 사용한다면 새 기기로 회선을 옮긴 후 삭제 여부를 확인합니다. eSIM 삭제만으로 요금제가 해지되지는 않으며, 필요한 경우 통신사에 문의합니다.

**최근 iOS의 로그아웃 화면:** Apple은 iOS 26 이상에서 로그아웃 시 기기를 지우거나 지우지 않고 로그아웃하는 선택지가 있을 수 있다고 안내합니다. 로그아웃만으로 데이터 삭제가 끝났다고 판단하지 말고, 기기를 판매할 때는 데이터 삭제를 완료합니다. 안드로이드로 바꾸는 경우 iMessage 등록 취소도 확인하고, 신뢰하는 기기 목록에서 이전 기기를 제거합니다. [Apple의 판매 전 안내](https://support.apple.com/ko-kr/109511)

Apple은 iCloud에 로그인한 상태에서 사진이나 연락처를 일일이 수동 삭제하면 연결된 기기와 iCloud에서도 삭제될 수 있다고 안내합니다. '모든 설정 재설정'은 개인 데이터를 지우지 않으므로 '모든 콘텐츠 및 설정 지우기'와 구분합니다. [Apple의 판매·양도 전 안내](https://support.apple.com/ko-kr/109511) · [설정 재설정과 데이터 삭제 차이](https://support.apple.com/ko-kr/126643) · [eSIM 삭제 안내](https://support.apple.com/ko-kr/102421)

**구형 기기 백업:** Apple은 iOS 8 이하에서 iCloud 백업을 더 이상 사용할 수 없다고 안내합니다. 필요한 자료는 컴퓨터 백업 등 가능한 방법을 확인하고, 백업이 실제로 완료됐는지 확인한 뒤 삭제합니다. [Apple의 iOS 8 이하 백업 안내](https://support.apple.com/ko-kr/120863)

**아이폰 모델 범위:** 최초 iPhone, iPhone 3G·3GS, iPhone 4·4s, 5·5c·5s, 6·6 Plus·6s·6s Plus, 7·7 Plus, 8·8 Plus, X·XR·XS·XS Max, SE 1·2·3세대, iPhone 11·12·13·14·15·16·17 계열의 일반·mini·Plus·Pro·Pro Max 및 e 모델, iPhone Air, iPhone 18 Pro·18 Pro Max, iPhone Duo를 포함합니다. 실제 판매된 세부 모델은 [Apple 모델 식별 안내](https://support.apple.com/ko-kr/108044)에서 확인합니다. 숫자 계열의 모든 접미사 조합이 실제 모델이라는 뜻은 아닙니다.

**선택 목록 참고:** 이 문서의 기종 범위와 실제 서비스의 선택 목록은 별도로 대조해야 합니다. 이전에 공유된 화면의 목록만으로 현재 개발 상태를 확정할 수 없으므로, 팀이 사용하는 최신 화면에서 선택 가능 여부를 확인합니다.

### 삼성 갤럭시

1. **설정 → 휴대전화 정보 → 소프트웨어 정보**에서 Android와 One UI 버전을 확인합니다. [삼성 버전 확인 안내](https://www.samsung.com/ae/support/mobile-devices/how-can-i-check-what-version-of-android-i-have-on-my-device/)
2. 백업 후 **설정 → 계정 및 백업 → 계정 관리**에서 기기에 연결된 Google 계정과 삼성 계정의 제거 절차를 확인합니다. 계정 암호가 필요할 수 있습니다.
3. **설정 → 일반 → 초기화 → 디바이스 전체 초기화**로 이동하고 안내를 확인한 뒤 초기화합니다. 화면 잠금이나 삼성 계정 인증이 필요할 수 있습니다.
4. 암호화한 SD카드를 계속 사용할 예정이라면 초기화 전 암호화 해제 여부를 확인합니다. SD카드는 별도로 확인·분리합니다.

**계정 잠금 확인:** 다음 사용자가 기기를 설정할 때 이전 Google 계정을 요구받지 않도록 초기화 전에 Google 계정을 제거합니다. 초기화를 마친 뒤에는 처음 시작하는 설정 화면인지 확인하고, 판매자 계정을 다시 등록하지 않습니다. [삼성의 초기화 및 초기화 보호 안내](https://www.samsung.com/uk/support/mobile-devices/how-do-i-perform-factory-reset-on-my-mobile-device/)

삼성은 위 경로를 Android 7 이상 예시로 안내하며 모델·버전에 따라 다를 수 있다고 설명합니다. 7 미만의 이전 기기는 삼성 안내의 이전 버전 경로를 확인합니다. 네트워크 초기화나 설정 초기화는 전체 데이터 삭제와 다릅니다. [삼성 초기화 및 계정 제거 안내](https://www.samsung.com/uk/support/mobile-devices/how-do-i-perform-factory-reset-on-my-mobile-device/) · [삼성 데이터 삭제 안내](https://www.samsung.com/ae/support/mobile-devices/how-do-i-delete-all-of-my-personal-information-from-my-device/)

## 1. 판매하기

**대상:** 기기 상태를 안내하고 구매자에게 판매하려는 사용자.

1. 제조사, 정확한 모델명, 저장 용량을 확인합니다.
2. 액정·뒷면·모서리 사진을 준비하고 흠집이나 파손을 기록합니다.
3. 기기 테스트 결과에서 통과·실패·확인 불가 항목을 구분합니다. 확인하지 않은 상태는 미확인으로 표시합니다.
4. 조사한 시세 자료의 모델·용량·상태와 가격 종류를 비교해 희망 가격을 정합니다.
5. 판매가 결정되면 공통 준비 절차를 마치고 거래 조건에 따라 전달합니다.

시세는 별도 조사 자료를 참고합니다. 서비스에서 배터리 상태를 직접 평가하지 않지만, 원자료의 업체 가격에는 배터리 조건이 반영됐을 수 있습니다. 따라서 실제 매입가나 거래 가격은 배터리 상태와 다른 검수 조건에 따라 달라질 수 있습니다. 서비스의 등록·거래 세부 절차는 확정 후 추가합니다.

**시세 자료 연결:** 함께 전달하는 CSV는 사용자가 선택한 기종·용량·상태에 대응하는 업체 매입 참고 범위입니다. 개발 연결 규격의 조건을 적용해 조회하고, 조회 결과가 없으면 '시세 정보 없음'으로 표시합니다. 업체별 가격과 등급 조건·출처는 각 행의 source_quotes_json에 포함되어 있습니다. 실제 서비스의 판매 확정가나 검수 후 지급액은 아닙니다.

## 2. 폐기: 나눔폰 기부·재활용

**대상:** 더 이상 사용하지 않는 휴대폰을 기부해 자원순환에 참여하려는 사용자. 나눔폰은 휴대폰 본체를 파손 여부와 기종에 관계없이 접수한다고 안내합니다.

나눔폰 FAQ는 액정이 깨졌거나 전원이 들어오지 않는 기기도 기부할 수 있다고 설명합니다. 센터는 개인정보 파기 절차를 안내하지만, **초기화할 수 없는 개별 기기의 사전 처리 조건은 확인되지 않았으므로** 1899-7047에 문의한 뒤 발송합니다. [나눔폰 FAQ](https://xn--910b51a865e.kr/front/bbsList.do) · [정부 수거 안내](https://mcee.go.kr/home/web/board/read.do?boardId=1887960&boardMasterId=713&menuId=10392)

1. [나눔폰 온라인 접수](https://xn--910b51a865e.kr/nanum/onlineApplication.do)에서 기부 형태, 영수증 및 탄소중립포인트 신청 여부를 선택해 접수합니다.
2. 자료를 백업하고 초기화한 뒤 접수한 품목과 수량에 맞게 포장합니다. 초기화할 수 없는 기기는 발송 전 나눔폰에 문의합니다.
3. 접수 완료 후 안내된 주소로 택배를 **착불** 발송합니다.
4. 발송 후 송장번호를 입력합니다.

**보내는 곳:** (17130) 경기도 용인시 처인구 이동읍 덕성산단1로 68번길 19, 수도권자원순환센터 나눔폰 담당자 앞  
**문의:** 1899-7047

**주의:** 온라인 접수 화면은 입고된 휴대폰이 파쇄되며 **입고 후 반환되지 않는다**고 안내합니다. 판매를 원하는 기기는 기부하지 않도록 합니다. 발송 전 현재 주소와 조건을 다시 확인합니다.

**탄소중립포인트:** 나눔폰은 조건을 충족한 휴대폰 본체에 대해 1대당 1,000원, 1인당 연간 최대 7만원을 안내합니다. 탄소중립포인트 녹색생활 실천에 먼저 가입하고, 정확한 수량으로 접수해 택배 발송과 송장번호 입력을 완료해야 합니다. 지급은 입고 확인 후 1~2개월이 걸릴 수 있으며 예산 소진 시 제한될 수 있습니다. 자세한 조건은 신청 시 확인합니다.

## 3. 폐기: 지역 수거함에 배출

**대상:** 거주지 근처의 지정 수거함에 직접 배출하려는 사용자.

1. 거주지 지자체 또는 행정복지센터의 폐휴대폰 수거함 설치 위치와 대상 품목을 확인합니다.
2. 공통 준비 절차를 마친 후 지정된 수거함에 배출합니다.
3. 포인트나 기부금 영수증을 원한다면 해당 수거 경로에서 제공되는지 먼저 확인합니다.

휴대폰을 일반 쓰레기로 버리는 대신 지자체가 안내하는 폐휴대폰 수거 경로를 확인합니다. 지역마다 수거 위치와 운영 방식이 다릅니다. [기후에너지환경부의 폐휴대폰 배출 안내](https://mcee.go.kr/home/web/board/read.do?boardId=1887960&boardMasterId=713&menuId=10392)는 행정복지센터 수거함과 나눔폰 접수를 안내합니다. 해당 자료의 2026년 9월 행사 혜택은 기간 한정이므로 상시 혜택으로 적용하지 않습니다.

## 4. 폐기: 다른 폐가전과 함께 방문수거 신청

**대상:** 휴대폰 외에 수거 대상 폐가전을 함께 배출하려는 사용자.

1. [폐가전 무상 방문수거의 품목·수량 기준](https://www.15990903.or.kr/portal/cnts/selectContents.do?cntnts_id=A1000005)과 지역별 신청 가능 여부를 확인합니다.
2. 휴대폰의 자료를 백업하고 초기화합니다.
3. 서비스 안내에 따라 대상 품목과 수량을 선택해 신청합니다.

휴대폰은 안내된 다량 배출 품목에 포함되어 있으므로 **휴대폰 한 대만으로 방문수거가 가능하다고 단정하지 않습니다.** 수거 조건은 신청 화면 또는 1599-0903에서 확인합니다.

## 서비스에 표시할 유의사항

- 모델명은 사용자가 입력하거나 선택한 값으로, 자동 검증된 기종이라고 단정하지 않습니다.
- 카메라로 촬영한 화질 테스트 사진과 판매 기기 자체의 외관 사진은 구분합니다.
- 서비스는 배터리 상태를 직접 평가하지 않습니다. 일부 업체는 매입가 산정 시 배터리 상태를 확인하므로 실제 가격이 달라질 수 있습니다.
- 수거기관의 운영 조건과 혜택, 지역별 수거함은 변경될 수 있으므로 공식 안내를 확인합니다.

## 개발 연결 규격

### 전달 파일과 범위

- 중고폰_시세_통합.csv: 한 행이 하나의 제조사·기종·저장 용량·선택 상태에 대응합니다. 설명·업체기준·미확인 목록 등 비가격 행은 없습니다.
- 7개 업체에서 확보한 개별 용량 중고 매입 참고가를 서비스 상태 분류에 대응해 집계했습니다. 미개봉 가격, 최대 용량 최고가 목록, 전 용량 공통값, 숫자 용량이 없는 값, 해결되지 않은 오류·충돌은 범위 집계에서 제외했습니다.
- 본문의 처리 안내는 제조사 및 설치된 운영체제 버전에 맞춰 표시합니다. 처리 안내에는 가격이 없어도 사용할 수 있는 절차가 포함되어 있습니다.
- 서비스 코드를 수정하거나 저장소에 파일을 배포한 것은 아닙니다. CSV를 읽고 화면과 연결하는 구현은 개발자가 진행합니다.

### 현재 테스트 결과와 연결

팀 저장소의 결과 형식은 device-hw-test/v1입니다. 제조사·기종은 device.declared.brand와 device.declared.model에 있습니다. 사용자가 선택한 값이므로 잘못된 입력 가능성을 유지합니다. [현재 결과 형식 설명](https://github.com/hojune02/gdgoc_hackathon_team1#6-json-설명서-다음-단계-담당자용)

**results.camera.profile.grade는 촬영한 사진의 화질 등급입니다. 시세 등급이나 외관 상태로 변환하지 않습니다.** camera.status 등 테스트 통과도 전체 기기 상태나 판매 등급을 보장하지 않습니다. 실패가 권한·설정 문제 때문일 수도 있으므로 실패만으로 고장 등급을 자동 확정하지 않습니다.

현재 결과에는 저장 용량과 외관·잔상 상태가 없습니다. device.deviceMemoryGB는 저장 용량으로 사용하지 않습니다. 시세 조회에서 다음 정보를 추가로 받습니다.

1. 저장 용량: 해당 기종에 CSV 행이 있는 storage 값 중에서 선택합니다. '모름'은 가격을 추정하지 않습니다.
2. 외관·화면 상태: 아래 condition_code에 해당하는 상태를 선택합니다.
3. 알려진 기능 이상: 있음·없음·모름으로 확인합니다. 정상 기능을 전제로 한 상태는 알려진 기능 이상이 없다고 응답한 경우에만 조회합니다. 모름이면 상태별 가격을 확정하지 않고 추가 확인을 안내합니다.

### 조회와 값 처리

| CSV 열 | 읽는 방법 |
| --- | --- |
| schema_version | phone-price-reference/v1 |
| reference_id | 행의 고유 식별자 |
| brand | Apple 또는 Samsung |
| model | 화면에 표시할 기종명. 가능한 경우 현재 기기 선택 목록의 표기와 일치시킴 |
| model_key | 기종 연결용 정규화 키. 아래 규칙 참고 |
| storage | 16GB, 64GB, 128GB, 256GB, 512GB, 1TB 등 정규화한 문자열 |
| condition_code | 아래 상태 선택값 |
| condition_label_ko / condition_description_ko | 상태 선택 라벨과 정의 |
| requires_no_known_function_fault | 문자열 true 또는 false. true는 알려진 기능 이상 없음 응답 필요 |
| reference_min_krw / reference_max_krw | 정수 원 단위 참고 범위. CSV를 읽은 뒤 숫자로 변환 |
| vendor_count / quote_count | 정수. 서로 다른 업체 수 / 포함된 원문 가격 수 |
| reference_kind | multi_vendor_reference 또는 single_vendor_reference |
| checked_on | 재대조한 날짜. 실시간 가격 기준일이 아님 |
| mapping_version | service-condition-map/v1 |
| notice_ko | 가격과 함께 표시할 설명 |
| source_quotes_json | JSON 배열 문자열. 업체·원래 등급·금액·상태 조건·가격 기준일·출처·검증 방법 포함 |

CSV는 UTF-8 BOM이며 쉼표·따옴표를 처리하는 CSV 파서로 읽습니다. 쉼표로 단순 분리하지 않습니다. source_quotes_json은 CSV 파싱 후 JSON 배열로 읽습니다.

조회 키는 **brand + model_key + storage + condition_code**입니다. 정확히 일치하는 행을 사용합니다. 용량·상태가 다른 행을 대신 사용하거나 결과가 없을 때 0원을 반환하지 않습니다.

model_key는 기종명을 소문자로 바꾸고 공백·괄호·점·가운뎃점·하이픈을 제거한 값입니다. Plus와 +는 plus, SE (2세대)는 se2, SE (3세대)는 se3에 대응합니다. 예: iPhone 12 → iphone12, iPhone 13 Pro → iphone13pro, Galaxy S23+ → galaxys23plus. 삼성 공식 모델명과 연결한 Galaxy A33 5G·A34 5G는 현재 선택 목록의 A33·A34에 대응시킵니다. LTE/5G 또는 s 접미사를 다른 모델에서 일괄 제거하지 않습니다. 확인되지 않은 지역명·별칭을 임의로 같은 기종으로 합치지 않습니다.

### 상태 선택값과 집계 규칙

이 분류는 서비스가 참고 가격을 제시하기 위해 정한 분류입니다. 업체 공식 공통 등급이나 검수 결과가 아닙니다. 업체의 상세 조건 차이는 source_quotes_json에 유지했습니다. 배터리를 평가하지 않는 서비스 특성상 가격을 '배터리 조건을 제거한 시세'로 표현하지 않습니다.

| condition_code | 선택 상태 | 포함한 원문 등급 |
| --- | --- | --- |
| clean | 흠집·파손·잔상 없음, 알려진 기능 이상 없음 | 민팃 A, 폰삼 S, Rediva A, 리템즈 A, 모아 A, 유즈폰 A |
| minor_wear | 생활 흠집, 파손·잔상 및 알려진 기능 이상 없음 | 폰삼 A, 리템즈 B, Rediva A-·B+, 모아 B, 유즈폰 A- 및 아이폰 B+ |
| visible_wear | 뚜렷한 흠집·찍힘, 파손·잔상 및 알려진 기능 이상 없음 | 폰삼 B, 리템즈 C |
| damage_or_fault | 파손 또는 알려진 기능 이상 | 폰삼 C, 리템즈 D, 모아 C. 손상 종류가 섞인 넓은 참고 범위 |
| display_fault | 화면이 정상적으로 표시되지 않음 | 폰삼 LCD불량, 한국스마트폰거래소 LCD 파손 |
| rear_damage | 후면 파손 | 한국스마트폰거래소 후면 파손. 다른 조건의 세부 허용 범위는 미확인 |
| burn_in | 잔상 있음, 화면은 표시되고 알려진 기능 이상 없음 | 민팃 B, 유즈폰 갤럭시 B+·B. 잔상 정도에 따른 금액 차이를 포함 |

일반적인 생활 흠집과 파손·잔상이 함께 있다면 깨끗함·생활 흠집·뚜렷한 흠집 분류를 선택하지 않습니다. 화면 표시 불량이면 display_fault, 잔상이 주된 문제면 burn_in을 우선 확인합니다. 복합 손상은 damage_or_fault 참고 범위의 한계를 표시하고 정확한 견적은 별도 검수로 확인합니다. 후면 파손 이외의 기능 이상도 알려져 있으면 rear_damage 하나만으로 견적을 확정하지 않습니다.

같은 기종·용량·서비스 상태에 들어간 가격의 하한 중 최솟값을 reference_min_krw, 상한 중 최댓값을 reference_max_krw로 집계했습니다. 업체 등급명이 같다는 이유로 합친 값은 아닙니다. 조건 대응이 불명확한 한국스마트폰거래소 A/B, 민팃 C/D 등은 임의로 다른 상태에 넣지 않았습니다.

vendor_count가 1이면 '단일 업체 참고가'라고 표시합니다. 최저·최고가가 같으면 하나의 금액으로 표시합니다. 그 외는 '업체 매입 참고 범위'로 표시하고 notice_ko를 함께 보여 줍니다. 실제 개인 간 판매가나 거래 보장가로 표시하지 않습니다.

가격 기준일은 source_quotes_json의 price_date와 price_date_source에서 확인합니다. checked_on을 가격의 유효기간이나 실시간 갱신 시각으로 사용하지 않습니다. 검색 수집본과 직접 조회 여부도 각 출처의 verification_method에 남아 있습니다.

### 확인 예시

현재 샘플 결과는 Apple / iPhone 12로 기록되어 있습니다. 사용자가 128GB와 clean을 선택하면 해당 키의 한 행을 조회합니다. 샘플의 카메라 사진 등급이 B여도 이 선택 상태를 B로 바꾸지 않습니다.

CSV에서 키가 없는 모델·용량·상태는 가격을 추정하지 않고 '해당 조건의 시세 정보 없음'으로 표시합니다. 현재 선택 목록 중 Galaxy S21 FE, A55, A54, A52, A71, A72, A73는 이 데이터의 정확한 표기·용량 가격과 연결되지 않았습니다. 다른 지역명이나 비슷한 모델의 가격으로 대체하지 않습니다.
