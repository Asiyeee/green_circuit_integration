# 시세 갱신 정책과 실행 범위 (2026-11-03, KST)

현재 화면은 **정적 CSV 조회**입니다. 실시간 검색·Gemini 검색 수집·일별 자동 수집은 구현하지 않았습니다. 현행 1,784행을 다시 수집하거나 최신 가격으로 바꾸지 않았습니다. 확인일은 2026-11-02이며 원문 기준일은 견적마다 다르거나 미표시입니다.

## 대상·주기

기존 7개 업체(폰삼, Rediva, 리템즈, 한국스마트폰거래소, 민팃, 모아, 유즈폰)의 개별 기종·용량·원래 등급 매입가와 등급 조건 페이지를 대상으로 합니다. 도입 제안 주기는 매일 09:00 KST **후보 수집/변경 검토**이며 팀 합의와 수집 경로 확인 후 활성화합니다. 상용 수집 전 각 사이트 접근 조건·공식 제공 경로를 확인합니다. 미래 기종처럼 보이는 원문 명칭도 자료에 있다는 사실만 보존하며 실제 모델 존재 여부/별칭이 확인됐다고 주장하지 않습니다.

검색 또는 Gemini grounding을 추가하더라도 실제 출처 링크·본문에서 **동일 모델, 용량, 등급, 조건, 금액**을 사람이 확인한 것만 후보로 만듭니다. 검색 요약/모델이 생성한 금액을 직접 반영하지 않습니다. LTE/5G/s를 일괄 제거하는 별칭 변환은 금지합니다. 현재 도구는 원문에서 숫자를 추출하거나 사실 여부를 자동 검증하는 도구가 아닙니다.

## 준비된 경로

```bash
npm run price:validate
node part2_price_disposal/scripts/price-refresh.js validate 후보.csv
node part2_price_disposal/scripts/price-refresh.js promote 후보.csv 검토.json
```

1. 기존 CSV와 같은 v1 전체 스냅샷을 `data/refresh-staging/` 등 git 제외 폴더에서 준비합니다. 원자료 CSV도 갱신 근거와 함께 별도 검토합니다. 이 도구는 원자료를 자동 수정하지 않습니다.
2. 스키마·정확한 키·중복 ID/키·기능 조건·날짜·양의 정수 금액·원문 견적과 집계 min/max·실제 업체 수·허용 업체 HTTPS 출처/조건 URL을 검사합니다. 같은 키 중복은 값이 같아도 실패시켜 조용히 마지막 값으로 덮어쓰지 않습니다. 같은 업체·기종·용량·등급의 상충 가격은 운영자가 원문 기준일/조건을 조사해 해결하기 전에는 후보에 넣지 않습니다.
3. 검토 JSON은 후보/기존 파일 SHA-256과 확인한 **모든 출처 URL별 로컬 증빙 파일 해시**를 갖춰야 합니다. 증빙은 검토 JSON과 같은 폴더 또는 그 하위 경로에 있어야 합니다. 스크립트의 허용 호스트 변경도 코드 리뷰 대상입니다. 파일 해시/확인 체크는 사람의 원문 대조를 대체하지 않습니다.
4. 성공 시 기존 CSV·검토 기록을 `data/refresh-backups/`에 보관하고 배타적 잠금과 rename으로 교체합니다. 실패·키 충돌·누락 증빙·기존 파일 변경 감지 시 서비스 파일을 유지합니다. 동일 writer 한 개만 운영합니다. 실패를 우회하려고 0원/다른 기종 가격을 채우지 않습니다.
5. `price.js`는 메모리 캐시를 사용하므로 **서버 재시작** 후 반영됩니다. 운영 배포는 석훈님 승인/통합 절차로 별도 진행합니다. 되돌릴 때 검토한 백업을 같은 후보 검증/승격 경로로 복원하고 재시작합니다.

검토 JSON 형식(금액 없음):

```json
{
  "candidateSha256": "후보 CSV 바이트 SHA-256",
  "baseSha256": "현재 CSV 바이트 SHA-256",
  "reviewer": "검토자",
  "reviewedAt": "ISO-8601 시각",
  "fullSnapshotConfirmed": true,
  "modelStorageGradeAmountsConfirmed": true,
  "sources": [{
    "url": "실제 원문 또는 등급 조건 URL",
    "verified": true,
    "evidenceFile": "evidence/원문.txt",
    "evidenceSha256": "보관한 실제 원문 바이트 SHA-256"
  }]
}
```

## 아직 필요한 설정

수집기/공식 피드 연동, 증빙 보관·검토 담당, 스케줄러(09:00 KST는 UTC 00:00), 실패 알림, 실행 머신 권한과 필요 자격증명 설정이 남아 있습니다. 자동 실행/워크플로를 켜거나 Gemini 키를 추가하지 않았습니다. 우선 검증 명령만 스케줄할 수 있으나 이는 신규 가격 수집이 아닙니다. 미확인 과거 가격을 확인일만 오늘로 바꾸는 방식은 사용하지 않습니다.
